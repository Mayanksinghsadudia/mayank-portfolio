Customer Management System

Stores customer profiles and orders in SQLite, with SQL summaries for total customers, orders and revenue, plus customer-level charts.

View source code & setup instructions on GitHub ↗

PythonStreamlitSQLitePandasMatplotlib

Implemented features

  • Add, view and delete customer profiles.
  • Record orders and join them to customer records.
  • Display total customers, total orders and summed order amounts.
  • Visualize order distribution and revenue per customer.

How the project works

Reports summarize records entered into the local app. Revenue is the sum of stored order amounts. The project does not implement customer tiers, fulfillment tracking or a measured growth study.

Explore the repository for the original project source, dependencies and local setup. Private configuration and existing local databases are excluded from public files.
