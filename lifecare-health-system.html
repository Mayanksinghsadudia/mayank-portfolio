MAYANK SINGH SADUDIA / ACADEMIC WEB APPLICATION

Lifecare Health System

An MCA academic prototype for patient and doctor registration, administrator approvals, appointment requests and profile management.

View source code & setup instructions on GitHub ↗

PythonFlaskSQLiteHTMLCSS

Implemented features

  • Register patients and doctors through web forms.
  • Review and approve registration requests in the administrator interface.
  • Request appointments and approve or reject them in the doctor interface.
  • View appointments and update patient or doctor profiles.

How the project works

This academic prototype demonstrates database and web workflows. It does not provide clinical predictions, department-capacity analytics or verified healthcare performance results. The public repository contains source and setup instructions; real patient records are excluded.

Explore the repository for the original project source, dependencies and local setup. Private configuration and existing local databases are excluded from public files.
