Amazon Review System

Classifies review text from Google Sheets as positive, neutral or negative with VADER, then explores the results with interactive charts.

View source code & setup instructions on GitHub ↗

PythonStreamlitVADERGoogle Sheets APIPandasPlotly

Implemented features

  • Select a Google Sheet, range and review-text column.
  • Classify each review using the VADER compound score.
  • Save sentiment labels to CSV and explore a results table, pie chart, histogram or scatter plot.

How the project works

The implemented thresholds are compound score > 0.5 for Positive, < -0.5 for Negative, and Neutral otherwise. Labels are automated estimates; no evaluated accuracy score or business improvement is claimed.

Explore the repository for the original project source, dependencies and local setup. Private configuration and existing local databases are excluded from public files.
