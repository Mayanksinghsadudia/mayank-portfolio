## 🌟 Key Highlights

- **Interactive 3D Presenter Studio**: Custom cinematic 3D workstation introduction showcasing dual analytical and creative expertise.
- **3D Curved Cylindrical Slider (35 Projects)**: Dribbble-inspired panoramic 3D card carousel featuring touch swipe, mouse drag, inertia snapping, and neon amber glowing UI.
- **Data Analytics & Engineering Case Studies**:
  - **Amazon Review Sentiment Analysis**: VADER NLP pipeline classifying customer feedback with live interactive charts.
  - **Online Retail Sales Analysis**: In-depth study of 541,909 UCI invoice records analyzing revenue, repeat customers, and country mix using Python & SQL.
  - **Customer Management System (CMS)**: SQLite relational schema with automated KPI reporting and metrics dashboards.
  - **Lifecare Health System**: Flask & SQLite medical record portal with role-based access control.
- **Creative Visuals, 3D & Brand Design**:
  - **3D Exploding Speaker Web App**: Interactive Three.js audio hardware exploded view mechanics.
  - **1968 Ford Mustang Fastback Showcase**: Real-time 3D automotive model exploration.
  - **Brand Identities & Packaging Mockups**: Custom vector logo marks, corporate stationery kits, beverage can 3D renders, and digital matte paintings.

## 🚀 Running Locally

To run the portfolio on your local machine:

```bash
# 1. Clone the repository
git clone https://github.com/Mayanksinghsadudia/mayanksinghsadudiaportfolio.git

# 2. Navigate to project root
cd mayanksinghsadudiaportfolio

# 3. Start local development server (Python 3)
python -m http.server 8000

# 4. Open in browser
# http://localhost:8000
```
